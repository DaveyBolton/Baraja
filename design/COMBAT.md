# Combat math — v1 baseline

- Player HP: 50 per run start
- Energy: 3 per turn
- Hand: draw 5 per turn, standard draw pile / discard pile / reshuffle
- Card costs: 1-2 energy (attacks, skills, powers all in that range)
- Enemy: telegraphed intent icon, 2-3 move pattern on a fixed cycle, no
  real AI needed for v1
- Run structure: 8-10 regular fights + 1 boss, linear (no branching map yet)

These are starting numbers, not final — expect this file to move once the
first fight is playable and gets tuned against actual card interactions.
